# Cry of the Philippine Revolution

A static slide presentation about the Cry of the Philippine Revolution, its historical accounts, and the evidence behind the date and location debate.

## Project files

The editable presentation is in `MyProject/`. Open `MyProject/index.html` in a browser. Use Previous/Next, the left and right arrow keys, Page Up/Page Down, or swipe on a phone. The Full button enters fullscreen mode.

## Deploy

The existing Vercel project serves the repository root. Before pushing changes made in `MyProject/`, run `./sync-vercel.ps1` to copy the current HTML, CSS, JavaScript, and image assets into the root. Vercel deploys the updated root after the GitHub push.

Image credits and historical references are included in the presentation.
